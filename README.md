# Shell in C++

A Unix-like command-line shell implemented from scratch in C++.

## Overview

This project explores the fundamentals of shell implementation, command parsing, process execution, and operating system interfaces.

## Technologies

- C++
- CMake
- POSIX system calls

## Features

- Built-in command handling
- Command parsing and execution
- PATH-based executable lookup
- Process management

*More features and documentation coming soon.*

## Building

```bash
cmake -S . -B build
cmake --build build
```

## Running

```bash
./your_program.sh
```
